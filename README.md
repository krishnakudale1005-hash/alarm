# 🌅 WakeLock - The Ultimate Smart Alarm App

**WakeLock** is a premium, high-performance smart alarm application designed to ensure you never oversleep again. Built with React Native and a robust SQLite backend, it forces your brain to wake up through interactive puzzles and physical activities.

## 🚀 Key Features

- **Multiple Alarms Management**: Set, toggle, and manage unlimited alarms with a clean, modern interface.
- **Advanced Wake-Up Tasks**:
  - **🧮 Math Puzzles**: Solve multi-step arithmetic problems to kickstart your brain.
  - **🧩 Grid Memory Game**: Follow and repeat complex visual patterns on a 3x3 grid.
  - **📱 Shake to Wake**: Vigorously shake your phone to hit the 100% progress goal—neend bhagane ka best tareeka!
- **Custom Ringtones**: Upload your favorite audio files (MP3/WAV) to use as personalized alarm sounds.
- **Premium Light Theme**: A stunning, clean, and professional UI with soft shadows and smooth animations.
- **Sleep Tracking**: Monitor your sleep duration and track your consistency with beautiful data visualizations.
- **Bedtime Mode**: A dedicated mode to help you wind down and track exactly when you hit the hay.

## 🛠️ Tech Stack

- **Frontend**: React Native (Expo)
- **Backend**: Node.js (Express)
- **Database**: SQLite
- **Styling**: Vanilla CSS / React Native StyleSheet
- **Sensors**: Expo-Sensors (Accelerometer)
- **Audio**: Expo-AV

## 📸 Professional UI

WakeLock features a state-of-the-art **Premium Light Theme** inspired by modern design trends like Glassmorphism and soft elevations. It's built to feel like a high-end utility app that fits perfectly on any modern smartphone.

## ⚙️ Installation & Setup

1. **Clone the repo**:
   ```bash
   git clone https://github.com/krishnakudale1005-hash/alarm.git
   cd alarm
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   cd backend
   npm install
   ```

3. **Run the Backend**:
   ```bash
   node server.js
   ```

4. **Run the Frontend**:
   ```bash
   npx expo start --web
   ```
